# Credits and Open Source Community

Cusimanse is built on the work of the broader open-source community. Thank you to the maintainers, contributors, reviewers, documentation authors and community members who make these projects possible.

## Agentic AI and coding-agent communities

- **goose** — open-source agent and native reference operator used by Cusimanse.
- **Agentic AI Foundation (AAIF)** — open ecosystem around open agentic-AI infrastructure and projects such as goose.
- **OpenAI Codex community** — developers and open-source contributors building with AI-assisted software engineering and coding-agent workflows.
- **Grok Build community** — developers exploring agentic software engineering, skills, plugins, hooks, MCP and subagent workflows.
- **Antigravity community** — developers building agentic development workflows around Antigravity; Cusimanse supports Antigravity as an adapter/operator path.

## Research infrastructure and observability

- **Numbat** — agent observability and research tooling that informs the Cusimanse observability model.
- **Lima** — disposable Linux VM infrastructure used for the Cusimanse execution boundary.

## Security and open-source ecosystem

Cusimanse also benefits from the wider security-research, Linux, Go, virtualization, observability, package-security and open-source communities.

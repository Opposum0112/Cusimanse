# AI use and research disclaimer

This repository contains software, automation, prompts, configurations, and documentation for controlled AI-agent and security research.

## Important limitations

- AI-generated plans, commands, analysis, and findings can be incorrect, incomplete, or unsafe.
- A model's output is not proof that an experiment, security control, or deployment step succeeded.
- Never treat an AI-generated statement as independent verification.
- Operators remain responsible for reviewing commands, permissions, network exposure, credentials, evidence handling, and applicable law or policy.
- Run untrusted workloads in disposable environments and keep host credentials out of experiments.
- Do not use this project against systems, accounts, networks, or data without authorization.

## Evidence standard

Claims about experiments should be backed by preserved evidence and, where required by the acceptance criteria, independently verified. A component that was not actually exercised must remain `NOT_DEPLOYED` rather than being represented as successful.

## AI providers and tools

References to AI models, agent harnesses, gateways, MCP servers, observability products, or other third-party tools do not imply endorsement, affiliation, or a guarantee of accuracy, availability, security, or fitness for purpose.

## No security guarantee

This project is a research/deployment framework, not a guarantee that a host, VM, agent, model, network, or third-party dependency is secure. Review the threat model and deployment state before each run.

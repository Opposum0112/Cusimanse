# Workload Triage Skill

Identify the workload, provenance, entry point, expected behavior and risk before execution.

## Procedure

1. Record source, hash, file type, size and acquisition metadata.
2. Identify declared entry points and build/install hooks.
3. Enumerate expected network, filesystem, process and privilege behavior.
4. Define hypotheses and indicators to observe.
5. Select static/dynamic/network/forensic skills required.
6. Produce a bounded research plan for approval.

Do not execute an unknown workload on the host.

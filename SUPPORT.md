# Support

Cusimanse is a beta research framework and runtime kit. Community support is provided on a best-effort basis.

## Before asking for help

1. Read `README.md` and `docs/RESEARCHER-GUIDE.md`.
2. Run `cusimanse doctor`, `cusimanse validate` and `cusimanse preflight`.
3. Include the Cusimanse commit, operating system, Go version, command run and relevant sanitized output.
4. Remove credentials, tokens, private paths and sensitive research evidence before posting.

## Questions and usage

Use GitHub Discussions or an issue when available for general questions, setup problems and reproducible bugs. Security vulnerabilities must follow `SECURITY.md` instead of a public issue.

## Scope

Cusimanse is experimental software. Community support does not replace review of security, authorization, policy or evidence requirements for your environment.
